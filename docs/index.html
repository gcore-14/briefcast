Get Started

Up and running in under five minutes.

Two API keys, a few lines of personalization, and you'll have your first briefing.

1

Install dependencies

Uses standard Python libraries. Requires Python 3.10+ for type hint syntax.

2

Set your API keys

Add your ANTHROPIC_API_KEY and optionally ELEVENLABS_API_KEY to a .env file.

3

Personalize your profile

Edit YOUR_INTERESTS and YOUR_PROFILE at the top of the file to match your background and priorities.

4

Run or schedule

Run once for an immediate briefing, or use --schedule for automatic daily delivery at 6 AM.

terminal 
# 1. Install dependencies
pip install feedparser anthropic requests \
    python-dotenv schedule elevenlabs

# 2. Create your .env file
ANTHROPIC_API_KEY=sk-ant-...
ELEVENLABS_API_KEY=your_key_here

# 3. Run once
python personal_podcast.py

# 4. Or run daily at 6:30 AM
python personal_podcast.py --schedule --time 06:30
